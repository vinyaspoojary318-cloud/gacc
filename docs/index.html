What gacc does

A thin, focused CLI on top of the official GitHub CLI.

🔄

Switch accounts instantly

Jump between personal, work, or any authenticated GitHub account with one command.

🚀

Create + push in one step

Initialize a repo, set the remote, and push — without leaving the terminal or guessing the account.

🔐

Uses official gh

Built on top of the GitHub CLI you already trust. No extra tokens or custom auth flows.

⚡

Zero config

Install, run gacc login, and you’re ready. Works with accounts already authenticated via gh.

Why gacc?

The usual multi-account flow is painful. gacc makes it painless.

✗ Without gacc

  1. Open GitHub in the browser
  2. Create the repository (hope it’s the right account)
  3. Copy the remote URL
  4. Come back to the terminal
  5. Add remote + push
  6. Realize you used the wrong account…

✓ With gacc

  • gacc use work — switch account
  • gacc create my-project — create + push
  • Done. Correct account. No browser.

Installation

Requires Python 3.9+ and the GitHub CLI.

1

Install GitHub CLI

If you don’t already have it:

brew install gh # macOS
# or see https://cli.github.com/
2

Authenticate your accounts

Log in with each GitHub account you use:

gh auth login
3

Install gacc

From source:

git clone https://github.com/vinyaspoojary318-cloud/gacc.git
cd gacc
pip install -e .
4

Start using it

gacc status
gacc list
gacc create my-new-project

Commands

Everything you need, nothing you don’t.

CommandDescription
gacc statusShow the currently active GitHub account
gacc listList all authenticated accounts
gacc use Switch the active account
gacc loginAdd / authenticate a new account
gacc create Create a repo and push (private by default)
gacc create --publicCreate a public repository
gacc create -d "desc" -a userCreate with description and specific account
gacc versionShow gacc version
